Privacy Policy

Application: YT Factory · Last updated: 7 November 2026 · Website: onelastmmm.top

1. About the application and the operator

YT Factory is a desktop application that helps a creator prepare short educational videos and upload them to the creator's own YouTube channel. The application is operated by its developer (an individual) for the developer's own channel. Contact: kolesnik@inbox.ru. This policy explains what information the application accesses, how it is used, where it is stored and how it can be deleted.

2. Google user data the application accesses

The application accesses Google user data only after the user authorizes it through Google's OAuth consent screen, and only for the following permissions:

ScopeData accessedPurpose
https://www.googleapis.com/auth/youtube.uploadThe ability to upload videos to the user's YouTube channel.Publishing the user's own finished videos.
https://www.googleapis.com/auth/youtube.force-sslMetadata of the user's own videos: title, description, tags, privacy status, scheduled publishing time.Setting and correcting the metadata and visibility of the user's own videos.
https://www.googleapis.com/auth/yt-analytics.readonlyAggregated performance statistics of the user's own channel: views, watch time, subscribers.Showing the user how published videos perform, to plan future videos.

The application also stores the OAuth access and refresh tokens that Google issues after authorization.

3. Information we do not collect

The application does not collect or store personal data of other people, viewers, commenters or subscribers of the channel. It does not collect passwords, payment information, contacts, location, or browsing history. It does not use cookies, advertising identifiers or third-party analytics.

4. How we use the data

Google user data is used only to provide the features described in section 2: uploading the user's own videos, editing their metadata and reviewing the statistics of the user's own channel. It is not used for advertising, profiling, credit or insurance decisions, or to train machine-learning models, and it is not sold.

5. Storage, security and retention

All data is stored locally on the user's own computer. The application has no servers or databases of its own. OAuth tokens are kept in a local file that is readable only by the user's operating-system account and is never published or shared. Statistics are kept only as long as needed to prepare reports and can be deleted at any time. Tokens are kept while the user uses the application and are deleted when the user revokes access or removes the application.

Short technical notifications (for example upload status or a summary of channel statistics) may be sent to the user's own private Telegram chat. These messages contain the user's own data and are addressed only to the user.

6. Sharing and disclosure

Google user data is not shared with, sold to or disclosed to third parties. Data flows only between the user's computer and Google/YouTube services through their official APIs, and to the user's own private chat as described above. Data may be disclosed only if required by law.

7. Your choices: revoking access and deleting data

You can revoke the application's access at any time at myaccount.google.com/permissions. After revocation the stored tokens stop working; delete the local token file to remove them completely. To request deletion of any data related to you, write to kolesnik@inbox.ru.

8. Compliance with Google policies

YT Factory's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy.

9. Children

The application is not directed to children under 13 (or the minimum age in your country) and does not knowingly collect their data.

10. Changes to this policy

We may update this policy. The current version is always available on this page, and the "Last updated" date shows when it last changed.

11. Contact

kolesnik@inbox.ru

Политика конфиденциальности

Приложение: YT Factory · Обновлено: 7 ноября 2026 г.

1. О приложении и операторе

YT Factory — приложение для ПК, помогающее автору готовить короткие познавательные видео и загружать их на собственный канал YouTube. Приложением управляет его разработчик (физическое лицо) для собственного канала. Связь: kolesnik@inbox.ru.

2. Какие данные Google используются

Только после авторизации пользователем на экране согласия Google и только для следующих разрешений:

  • youtube.upload — загрузка собственных готовых видео на канал пользователя;
  • youtube.force-ssl — просмотр и изменение названия, описания, тегов, настроек доступа и времени публикации собственных видео;
  • yt-analytics.readonly — чтение сводной статистики собственного канала (просмотры, время просмотра, подписчики), чтобы планировать следующие видео.

Также хранятся токены доступа OAuth, выданные Google.

3. Что мы не собираем

Данные других людей, зрителей, комментаторов и подписчиков, пароли, платёжные данные, контакты, геолокацию и историю браузера. Файлы cookie, рекламные идентификаторы и сторонняя аналитика не используются.

4. Как используются данные

Только для функций из п. 2. Данные не используются для рекламы, профилирования, обучения моделей машинного обучения и не продаются.

5. Хранение, защита и сроки

Все данные хранятся локально на компьютере пользователя; собственных серверов и баз данных у приложения нет. Токены лежат в локальном файле, доступном только учётной записи пользователя, и не публикуются. Токены хранятся, пока пользователь работает с приложением, и удаляются при отзыве доступа. Краткие технические уведомления (статус загрузки, сводка статистики) могут отправляться в личный чат пользователя в Telegram и адресованы только ему.

6. Передача данных

Данные Google не передаются, не продаются и не раскрываются третьим лицам; они идут только между компьютером пользователя и сервисами Google/YouTube по официальным API и в личный чат пользователя. Раскрытие возможно только по требованию закона.

7. Отзыв доступа и удаление данных

Доступ можно отозвать на myaccount.google.com/permissions; после этого токены перестают действовать, а локальный файл токена удаляется. Для удаления данных пишите на kolesnik@inbox.ru.

8. Соответствие политикам Google

Использование и передача информации, полученной из API Google, соответствуют Политике по пользовательским данным в сервисах API Google, включая требования ограниченного использования (Limited Use). Приложение использует сервисы YouTube API; вы также принимаете Условия использования YouTube и Политику конфиденциальности Google.

9. Дети и изменения

Приложение не предназначено для детей и не собирает их данные. Политика может обновляться; актуальная версия всегда на этой странице.
